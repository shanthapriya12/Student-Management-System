# Student Management System

A Python-based Student Management System that allows users to manage student records using SQLite.

## Features

- Add student
- View all students
- Search student by roll number
- Update student details
- Delete student
- Input validation
- Email and phone validation
- SQLite database storage
- Object-Oriented Programming

## Technologies Used

- Python
- SQLite
- Regular Expressions (Regex)
- Object-Oriented Programming
